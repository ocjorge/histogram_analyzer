# 📊 Análisis y Ecualización de Histogramas en Imágenes

## 📄 Descripción
Este script permite seleccionar una imagen desde el sistema de archivos, mostrarla junto con su histograma de intensidades, calcular y mostrar también la imagen ecualizada y su histograma correspondiente. Además, imprime en consola las frecuencias de cada nivel de intensidad (de 0 a 255) tanto para la imagen original como para la ecualizada.

---

### 🧰 Requisitos

Para ejecutar este programa, necesitas tener instaladas las siguientes bibliotecas:

- `opencv-python` (`cv2`)
- `numpy`
- `matplotlib`
- `tkinter` (viene incluido con Python)

Puedes instalar las dependencias faltantes usando pip:

```bash
pip install opencv-python numpy matplotlib
